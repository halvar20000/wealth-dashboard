# Wealth Dashboard

Self-hosted net worth tracking inside Home Assistant. One SQLite file in
the add-on's data folder, no cloud, no telemetry, no account with anybody.

Manual accounts, broker CSV import (Degiro, Trade Republic, Finary and
more), holdings, cash flow, budgets, subscriptions, self-learning
categories, goals, loans, retirement — and optional read-only bank sync
over PSD2 via Enable Banking, with credentials that stay yours.

English, German, French and Spanish. Opens in the Home Assistant sidebar
through ingress; nothing to configure before the first start.
